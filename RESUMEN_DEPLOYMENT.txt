═══════════════════════════════════════════════════════════════════════════
  🚀 CÓMO DESPLEGAR EN RAILWAY (3 MINUTOS)
═══════════════════════════════════════════════════════════════════════════

1. Ir a: https://railway.app

2. Iniciar sesión (con GitHub si es posible)

3. Click en "New Project"

4. Seleccionar "Deploy from GitHub repo"

5. Buscar: "lume-portal-react" 
   (O seleccionar: Crisalinas/lume-portal-react)

6. Click en "Deploy"

7. Esperar 2-3 minutos mientras Railway:
   - Clona el repositorio
   - Ejecuta: npm install
   - Ejecuta: npm run build  
   - Inicia: npm start (servidor serve)

8. Obtener URL pública:
   - Click en "Settings"
   - Sección "Domains"
   - Click "Generate Domain"
   - Tu portal estará en: https://[nombre].up.railway.app
