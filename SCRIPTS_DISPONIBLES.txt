  📜 SCRIPTS DE DEPLOYMENT DISPONIBLES
═══════════════════════════════════════════════════════════════════════════

Tienes 4 scripts .bat para facilitar el deployment:

═══════════════════════════════════════════════════════════════════════════
  🔐 1_LOGIN_RAILWAY.bat
═══════════════════════════════════════════════════════════════════════════

**Ejecutar primero (solo una vez)**

Qué hace:
  - Abre el navegador
  - Te pide que inicies sesión en Railway con GitHub
  - Autoriza Railway para acceder a tus repositorios
  - Guarda la sesión

⏱️ Tiempo: 1-2 minutos
🎯 Resultado: Sesión iniciada en Railway CLI

═══════════════════════════════════════════════════════════════════════════
  🚀 2_DEPLOY_RAILWAY.bat
═══════════════════════════════════════════════════════════════════════════

**Ejecutar después del login**

Qué hace:
  - Verifica que hayas iniciado sesión
  - Inicializa el proyecto en Railway
  - Despliega el Portal LUMÉ
  - Ejecuta build automáticamente

⏱️ Tiempo: 3-5 minutos
🎯 Resultado: Portal desplegado en Railway

═══════════════════════════════════════════════════════════════════════════
  ⚡ DEPLOY_RAPIDO.bat
═══════════════════════════════════════════════════════════════════════════

**Para actualizaciones futuras**

Qué hace:
  - Hace commit de cambios
  - Push a GitHub
  - Railway auto-despliega

⏱️ Tiempo: 1 minuto
🎯 Resultado: Cambios desplegados automáticamente

═══════════════════════════════════════════════════════════════════════════
  🔧 DESPLEGAR_EN_RAILWAY.bat
═══════════════════════════════════════════════════════════════════════════

**Script completo todo-en-uno**

Qué hace:
  - Verifica Node.js
  - Instala Railway CLI si no existe
  - Hace login
  - Configura proyecto
  - Despliega

⏱️ Tiempo: 5-7 minutos
🎯 Resultado: Todo automatizado

═══════════════════════════════════════════════════════════════════════════
  📋 CÓMO USAR (Primera vez)
═══════════════════════════════════════════════════════════════════════════

OPCIÓN A: Paso a paso (Recomendado)
────────────────────────────────────

1. Doble click en: 1_LOGIN_RAILWAY.bat
   → Inicia sesión con GitHub en el navegador
   → Vuelve a la ventana cuando termine

2. Doble click en: 2_DEPLOY_RAILWAY.bat
   → Selecciona "Create new project" cuando pregunte
   → Espera 2-3 minutos
   → ¡Listo!

OPCIÓN B: Todo automático
──────────────────────────

1. Doble click en: DESPLEGAR_EN_RAILWAY.bat
   → Hace todo automáticamente
   → Solo sigue las instrucciones

═══════════════════════════════════════════════════════════════════════════
  🔄 ACTUALIZACIONES FUTURAS
═══════════════════════════════════════════════════════════════════════════

Después del primer deploy, para actualizar:

1. Haz cambios en el código
2. Doble click en: DEPLOY_RAPIDO.bat
3. ¡Listo! Railway despliega automáticamente

O simplemente:
  git add .
  git commit -m "Cambios"
  git push origin main

Railway detecta el push y despliega automáticamente.
